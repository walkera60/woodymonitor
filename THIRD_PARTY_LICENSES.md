# Third-Party Software and Attribution

Woody Monitor contains and/or builds upon software originating from
third-party open-source projects.

## PellMon

Woody Monitor uses and builds upon communication and protocol work from
the PellMon project.

PellMon is an open-source monitoring and configuration solution for
pellet burners.

Original project:

https://github.com/motoz/PellMon

Copyright and authorship notices contained in the original PellMon source
code are retained.

In particular, parts of the NBE/Scotte communication implementation contain
copyright notices for:

Copyright (C) 2013 Anders Nylund

The relevant source files retain their original copyright and GNU General
Public License notices.

PellMon specifically provides the ScotteCom and NBEcom components for
communication with NBE pellet burner controllers, including NBE
Scotte/Woody/Biocomfort controllers.
